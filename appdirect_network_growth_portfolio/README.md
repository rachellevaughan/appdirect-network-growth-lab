# AppDirect × PartnerStack — Network Growth Command Center

A Streamlit portfolio project created for the **Network Growth Analyst** opportunity at AppDirect / PartnerStack.

## What this demonstrates

- Weekly network growth diagnostics
- Partner activation segmentation
- Two-sided marketplace health analysis
- GMV / commission concentration analysis
- Growth experiment design
- Activation-driven financial forecasting
- Executive-ready recommendations
- SQL / BigQuery-oriented analytical thinking

> **Important:** all company metrics, partnership names, and forecasts in the demo are synthetic and illustrative.

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deploy on Streamlit Community Cloud

1. Create a GitHub repository.
2. Upload `app.py`, `requirements.txt`, and the `assets/` folder.
3. In Streamlit Community Cloud, select the repository and set the main file to `app.py`.
4. Deploy.
